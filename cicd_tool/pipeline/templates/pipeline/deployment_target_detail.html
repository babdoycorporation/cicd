How to use

In a pipeline step, use:

deploy:{{ target.target_type }}:{{ target.pk }}

Set this as the step command to trigger this connector. The worker will inject credentials and execute the appropriate SDK/CLI automatically.

Example YAML: 
stages:
  - name: Deploy
    steps:
      - name: Push to {{ target.name }}
        command: deploy:{{ target.target_type }}:{{ target.pk }}
